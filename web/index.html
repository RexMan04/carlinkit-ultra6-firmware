Firmware update

Installed: loading...

Accepts project builds for this model and base, older test builds, and the stock firmware (rollback). The checks prove the file is intact and built on the stock 202610121756C base; they do not prove who made it. Install rewrites the recovery, kernel and system partitions and restarts the adapter, usually more than once.

Recovery

Video processing

Switch CarPlay back to the adapter's stock re-encoding (what the adapter did before this project). Takes effect the next time CarPlay connects.

Project settings

Pass-through on and audio delay back to "phone decides". Other settings are unchanged.

Stock factory reset

Runs the adapter's own factory reset: clears the stock settings (hotspot channel, startup delay, GPS, force display, audio delay, background mode, LED mode), deletes the adapter's sd.db database (likely the paired-phone list) and restarts the adapter. Pass-through and audio stream mode are not changed by it.

Go back to stock firmware

Download v5_202610121756_STOCK_rollback.swu from the project's GitHub release, choose it under Firmware update, upload, then install. This removes this page; any later project install needs the first-install bookmark again. Rolling back has not yet been tested on a real adapter, and there is no known recovery mode if an install fails.
